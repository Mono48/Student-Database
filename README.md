# Student Database

## Project Description
This project is a fictional student database
created using Python and SQLite.

It stores student information, including
department, level, attendance average and
average examination score.

## Database Fields
- Student ID
- Department
- Level
- Attendance Average
- Average Examination Score

## Technologies Used
- Python
- SQLite
- SQL

## Number of Records
10 student records.

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Run the following command:

python create_database.py

## How to View the Database

The database can be viewed using DB Browser for SQLite.

1. Download the repository by clicking the Code button
   and selecting Download ZIP.
2. Extract the downloaded ZIP file.
3. Open DB Browser for SQLite.
4. Click Open Database.
5. Select the student_database.db file.
6. Navigate to the Browse Data tab.
7. Select the students table.

All student records will be displayed in rows and columns.

## Note
All student information in this database
is fictional.
Attendance and examination scores are
stored as percentages.
